## About

TR Enterprise is a registered 1st class contractor firm based in Birampur, Dinajpur, Bangladesh, with a technology division that builds AI, machine learning and data solutions.

This repository contains the company's single-page website.

## Website features

- Animated neural-network hero that reacts to the mouse or touch
- Interactive process explorer for three solution types: document chatbot, vision system and data agent
- Company profile panel with a live license-validity meter
- Portfolio of selected AI projects
- Built-in FAQ assistant that answers questions about the company (runs entirely in the browser)
- Contact form that opens the visitor's email app with the message ready to send
- Responsive layout and keyboard-accessible controls

## Built with

HTML5, CSS3 and vanilla JavaScript. No frameworks and no build step. Hosted free on GitHub Pages.
